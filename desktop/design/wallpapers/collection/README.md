# Zaod OS built-in wallpapers

The owner supplied these images for the image; each one is cropped to 2560x1440
and saved as a progressive JPEG so swaybg and the login screen can show it
without any SVG loader.

| File | What it shows |
| --- | --- |
| `zaod-night-pier.jpg` | A pier on a still lake under stars, comets and a crescent moon (default) |
| `zaod-ascension.jpg` | A lone figure lit from above inside a shattered dark shell |
| `zaod-purple-sunset.jpg` | Violet sunset over a mirror-calm lake |
| `zaod-torii-blossom.jpg` | A torii gate under red blossom and cold blue mist |
| `zaod-alpine-lake.jpg` | Alpine peaks and autumn larches reflected in a turquoise lake |
| `zaod-sunset-cabin.jpg` | Flat-art sunset cabin on a lake |
| `zaod-golden-road.jpg` | A golden country road between fields at dawn |
| `zaod-starlit-tree.jpg` | One tree under the Milky Way above glass-blue water |
| `zaod-gold-folds.jpg` | Black and gold folded ribbons on a dark field |

Provenance: supplied by the Zaod OS owner for the operating system. The originals
arrived as chat-sized images, so each was scaled with Lanczos resampling and a
light unsharp mask. Replace a file with a native-resolution version of the same
name when one is available; nothing else has to change.

A Spider-Man wallpaper was also sent but is left out on purpose: it is Marvel
artwork and cannot be redistributed inside an operating-system image. Nothing
else was dropped.

Switch the desktop wallpaper with `zaod-wallpaper <name>` (see
`desktop/shell/zaod-wallpaper`), or list what is installed with
`zaod-wallpaper --list`.
