# Web app icons: trademark notice

The six icons in `icons/` label the optional web apps that the store offers. Each
file is an SVG drawn in this repository, but the glyph inside it is the service's
own logo, which is a trademark of that company. They are included for one reason:
so a link to the service is recognisable in the launcher. Nothing here implies
endorsement, partnership or sponsorship, and the marks are not covered by the
project's own licence.

| File | Service | Trademark owner |
| --- | --- | --- |
| `zaod-web-youtube.svg` | YouTube | Google LLC |
| `zaod-web-whatsapp.svg` | WhatsApp | Meta Platforms, Inc. |
| `zaod-web-instagram.svg` | Instagram | Meta Platforms, Inc. |
| `zaod-web-facebook.svg` | Facebook | Meta Platforms, Inc. |
| `zaod-web-tiktok.svg` | TikTok | ByteDance Ltd. |
| `zaod-web-x.svg` | X | X Corp. |

The web apps themselves are not bundled: the store writes a small `.desktop` file
that opens the service in a Chromium app window, so the page, its content and its
own terms of service are the service's, not this OS's.
